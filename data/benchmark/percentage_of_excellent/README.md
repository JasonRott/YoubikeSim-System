# 真實 benchmark：站點優良時段占比（percentage of excellent）

本資料夾保存組員從**真實 YouBike 資料**算出的「站點優良時段占比」基準，供模擬校準與比對。

## 指標定義

- **優良**：站內車輛數維持在容量 **20%–80%** 之間（既非缺車也非滿站）。
- **優良時段占比**：一天中（限 **06:00–23:59**）站點處於「優良」的時間比例。
- 系統表現：所有站點此指標的平均；極端站：看分布左尾 / 低百分位。

## 檔案

- `站點優良時段比例.csv`：**每站每日**優良時段占比。
  欄位：站點代號、日期、單日優良時段占比。38,257 列（1744 站 × 22 天）。
- `每日站點優良時段比率_平均.csv`：**每日全系統平均**（22 天，2026-04-28 ~ 2026-05-19）。值域約 0.53–0.69。
- `percentage_of_excellent.png`：全部站點-天的分布直方圖（含 P5 / P10 / 中位數標線）。

## 真實 benchmark 統計（由 `站點優良時段比例.csv` 精算）

```text
station-days = 38,257（1744 站 × 22 天，2026-04-28 ~ 2026-05-19）
mean   = 0.607
median = 0.603
P5     = 0.246   （極端惡劣區）
P10    = 0.329   （嚴重警戒區）
P25    = 0.457
P75    = 0.766
P90    = 0.910
== 1.0（全天健康）比例 = 4.2%
<= 0.25（極端惡劣）比例 = 5.2%
```

## 用途（time-to-fail 校準）

- 真實系統「永不 fail」：在有 YouBike 內生調度下，這個分布長期維持（系統日均約 0.6）。
- 我們的**無調度模擬**應產生同指標，觀察從何時開始顯著低於此 benchmark（divergence / time-to-fail），
  作為校準與後續調度策略評估的基準（見 `system_upgrade/architecture_narrative.md` 第 10 節）。
- 比對維度：系統日均、分布（左尾肥厚程度）、低百分位（P5/P10）。
