# 2. 調度政策設計與參數

## 2.1 共用機制（所有區內政策共享）
**水位帶（容量比例）**
| 帶 | 比例 | 用途 |
|---|---|---|
| 優良帶 | 20–80% | 指標 PoE 計算 |
| **缺車/滿站警戒線 LCL/UCL** | **20% / 80%** | 站點 <20%→需補、>80%→需抽 |
| 服務目標（補/抽到此）| **補到 70% / 抽到 30%** | 卡車把站拉到此水位 |
| 反應警戒帶（P3/P6 用）| **10% / 90%** | 更極端、保留車力的反應觸發 |
| 危急（P2 用）| **0% / 100%** | 全空或全滿，立即出車 |
| 行動門檻 min_action | **0.15** | 偏離/容量 <0.15 不值得服務 |

**選站分數（貪婪選站）**
> 偏離 = 缺車站(補車目標70% − 現量) 或 滿站(現量 − 抽車目標30%)
> **Score = 偏離 /（距離 + 常數）**（線性）　或　**Score = 偏離² /（距離 + 常數）**（平方）
- 平方版**放大極端站、削弱距離權重**（優先救最嚴重站）。
- 常數：線性 0.1、平方 0.5。同分隨機。
- **卡車約束**：車上有車才能補、有空位才能抽。
- **P5 需求加權（可選）**：Score ×（站日借車量 λ）^α；α 預設 0（=不加權），可設 0.5（=√λ，高人氣站優先）。

## 2.2 七種政策的完整運作
- **P1 固定巡迴**：排定每日 **2 班（05:30、15:30）各 90 分**；班內用**線性 Score** 貪婪選站、把站補/抽到健康目標；**整班計薪**。純排程、不對突發反應。
- **P2 動態觸發**：全天待命、**每 5 分掃描**；**觸發＝區內有站全空(0%)或全滿(100%)、或破 20/80 的站數 ≥3**；觸發即出車、用**平方 Score** 服務到全區健康；出車後**冷卻 10 分**。
- **P3 反應式預期**：兩模式混合——①尖峰前（05:30、15:30）排定**預置巡迴**（平方 Score）；②其餘時間待命，當**破警戒帶 10/90 的站數 ≥3** 即反應出車（比 20/80 更極端才動、保留車力應付尖峰）。
- **P4 智慧轉移**：沿用 P1 的固定班次（05:30、15:30）但班內改用**平方 Score**、且**全區健康就提早收工**省成本；整班計薪。
- **P6 預測式預置**：尖峰前（05:30、15:30）做**預測式預置**——用逐時借車率預測**未來 3 小時**借走量，把每站推到 **預測目標 = min(容量, 0.65×容量 + 預測流出量)**（即**預先補滿「將被借空」的站**）；其餘時間反應警戒帶 10/90。
- **P7 配對協調（主角）**：全天值勤、每 5 分重解，見 §2.3。
- *（P5 為需求加權旗標，疊加於上述選站分數，非獨立政策。）*

## 2.3 P7「配對協調」規則
- 每次掃描**全域評估所有「盈餘站 → 赤字站」配對**，挑分數最高者：
  > **Score = 可搬車量 /（卡車→盈餘站距離 + 盈餘站→赤字站距離 + 0.5）**
- 卡車**鏈式作業**：到盈餘站**抽車到 30%** → 直送赤字站**補到 70%**，**繞過集散場往返**（效率最高）。
- 無合適配對 → 退回集散場補車／停放多餘（守恆）。
- **每次掃描重新求解**——攻多車「協調」損失（多台車各自為政會互相干擾）。

## 2.4 夜間跨區調度 — 虛擬結算法（母車）
| 參數 | 值 |
|---|---|
| 對象 | 各區**集散場**（不直接到站；白天 P7 再分到站）|
| 母車容量 / 車速 | **100 輛 / 30 km/h** |
| 裝卸時間 | **3 + 0.5×台數** 分/訪（取 + 卸 = 2 訪）|
| 夜間時窗 | **00:00–04:00 = 240 分** |
| 母車人力費率 | **NT$400 / 工時**（夜班，白天 300 × 1.33）|
| 母車數 | = ⌈夜間作業工時 / 240 分⌉ |
| 配對法 | **貪婪最近對**：盈餘區 → 赤字區（組員 Policy 2）|
| 車輛來源 | 從盈餘區**過滿站點回收**（守恆）|

> 角色分工：**白天 P7 平衡區內、夜間虛擬結算平衡跨區。**
