# 最終任務結果

本資料夾為專案最後階段的產出（已完成）。

## 1. 最終 SC/EC 效率前緣（target 帶 × ∝需求車隊 × 多 seed）
- 網格：target 帶 {0.40/0.60, 0.35/0.65, 0.30/0.70, 0.25/0.75} × ∝需求總車隊 {52, 78, 104, 130, 156} × 3 seed，
  每點 7 天連續、夜間虛擬結算、取 day5–7 穩態。共 60 次。
- 圖：`../圖表/7_最終Pareto效率前緣.png`（A=品質-成本前緣、B=品質↔效率撥盤）。
- seed 間標準差僅 ~0.001–0.002（結果穩健）。

**膝點（邊際遞減轉折）在 104 台**（PoE 每 +26 台增益）：

| 車隊（∝需求）| 52 | 78 | 104 | 130 | 156 |
|---|---|---|---|---|---|
| PoE（band 0.40/0.60）| 0.535 | 0.590 | **0.601** | 0.604 | 0.607 |
| 邊際增益 | — | +0.056 | +0.011 | +0.003 | +0.002 |

→ 104 台即達 **0.60 品質門檻**；再加車 PoE 飽和、成本卻線性上升。
